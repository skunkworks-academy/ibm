Final assessment: production-readiness scenarios

Recommended time: 2 hours including review

This assessment measures integrated DBA judgment across the four course parts. It deliberately favors scenario reasoning over syntax recall.

Assessment rules​

  • 16 questions.
  • One best answer per question.
  • Pass threshold: 75%.
  • Your best score is retained in this browser.
  • After submitting, each question shows a rationale to guide targeted review.
  • A passing attempt marks the final-assessment milestone complete.
  • If launched inside a compatible SCORM 1.2 LMS, the best score and pass/fail status are reported when the SCORM API is available.
  • The exported completion record is browser-local evidence for this independent learning companion; it is not an IBM certification or official IBM course completion record.
Before you submit

For each question, choose the response that best preserves evidence, limits blast radius, respects recovery/security controls and tests a causal hypothesis.
